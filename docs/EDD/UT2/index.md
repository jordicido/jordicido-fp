# UT2 - Instalación y uso de entornos de desarrollo

## Contexto

En esta unidad, nos centraremos en la instalación y uso de entornos de desarrollo integrados (IDEs) y otras herramientas esenciales para el desarrollo de software. Un entorno de desarrollo es un conjunto de herramientas que facilitan la escritura, depuración y ejecución de código. Estas herramientas pueden incluir editores de texto, compiladores, depuradores, sistemas de control de versiones y más.

En esta unidad trataremos temas relacionados con la instalación y uso de entornos de desarrollo como por ejemplo:

- [Configuración de un entorno de desarrollo](sesion2.md)
- [Depuración de código](sesion3.md)
- [Herramientas de automatización](sesion4.md)
